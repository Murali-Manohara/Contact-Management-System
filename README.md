# Contact Management System

A simple command-line Contact Management System developed using Python.

This project was created as part of the Software Foundations graded project. It demonstrates basic Python programming, data structures, modular programming, algorithm efficiency, and basic concurrency concepts.

---

## 1. Project Overview

The Contact Management System allows a user to:

- Add a new contact
- Display all saved contacts
- Search for a contact using Contact ID
- Update the phone number of an existing contact
- Exit the application

The application stores contact information in memory using a Python dictionary.

No database is used in the current implementation because the project requirements specify in-memory storage.
